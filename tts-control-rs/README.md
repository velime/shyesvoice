# TTS Control (Rust)

Rust-версия KavaTts: egui/eframe для интерфейса, windows-rs для SAPI 5 и глобальных горячих клавиш. Один `kava_tts.exe`, без .NET.

Настройки лежат в `%LOCALAPPDATA%\KavaTts\settings.json` (тот же файл и формат, что у C#-версии).

## Что нового
- **Переключатель голосов** — карточка «Голос», показывает все установленные SAPI-голоса. Maxim выбирается по умолчанию, если установлен.
- **Перезапуск Windows Audio** — кнопка под выбором вывода. Перезапускает `Audiosrv` и `AudioEndpointBuilder`, нужен запрос UAC. После этого SAPI и список устройств пересоздаются.
- **Вылеты при повышении тона** — убраны причины: голос/устройство больше не переустанавливаются на каждой фразе, перед новой фразой старая останавливается, из текста вырезаются недопустимые для XML символы, ошибки и паники SAPI-потока не валят программу.
- **Интерфейс** — строго чёрно-белый, без цветных оттенков.

## Сборка
Нужен Rust (toolchain `stable-x86_64-pc-windows-gnu`) и MinGW-w64 в `PATH` по пути без пробелов (GCC не линкует из пути с пробелами).

```powershell
cargo build --release     # target\release\kava_tts.exe
cargo test                # unit-тесты
cargo test -- --ignored   # тест SAPI: 60 быстрых фраз с тоном +10 (беззвучно)
```

Голос IVONA Maxim в репозиторий не входит: он лицензируется отдельно, установщик — на сайте Harpo.
